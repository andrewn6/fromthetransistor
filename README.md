## From the transistor to the web browser.

I wanted to take this on to really re-build my understanding of computers from the ground up, and go deeper into hardware, embedded systems, etc.

This is currently a work in progress project, with half of the sections done

PSA: There are a few changes from George's outline in the original fork. We do not design our own FPGA, but the rest of the toolchain is done and tested thru verilator. I.e the CPU is built out, drivers, OS, etc.

I plan to create markdown/a collective PDF with resources in a course style to share what I learnt from this outline.
