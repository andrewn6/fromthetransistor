## mmu plan (this is the task)

design decisions (already made, keep unless user vetoes):
- 4KB pages, single-level table: va[11:0] offset, va[31:12] vpn.
  pte[0] present, pte[1] writable, pte[2] user-ok, pte[31:12] frame.
  table = 4096 ptes = 16KB at ttbr (kernel sets per process).
- unified TLB, 32 entries, direct-mapped (cpu has one memory port,
  fetches and loads/stores share it, no I/D split).
- hardware walk on miss: mmu sits between cpu and soc decoder, stalls
  the cpu's access and uses the bus itself to fetch the pte, then
  completes. no exception-based refill.
- mmio windows (uart/eth at 0x4000xxxx) bypass translation, hit the
  decoder unmapped.
- en==0 = pure pass-through, same clock, zero behavior change. this is
  what keeps every existing test green while paging is off.

batches (send code one at a time in chat when user says "batch N"):
1. mmu.v skeleton - ports, va/pte layout, pass-through. standalone lint.
2. tlb - 32-entry direct-mapped, tag array, pte array, valid bits,
   combinational lookup, flush input.
3. walk fsm - on miss: stall cpu, read pte at ttbr + vpn*4 over the
   bus, refill tlb, retry the access. needs a "busy" handshake so
   soc/tb hold the cpu's cycle.
4. faults + ctrl - invalid pte / not-writable store / user violation
   -> fault output. mmio ctrl regs (enable, ttbr write flushes tlb).
5. soc.v rewiring - cpu -> mmu -> decoder, mmio bypass in front of
   translation, ctrl window (suggest 0x40003000).
6. address-space switch - kernel writes ttbr (auto-flush), that is
   the whole context switch. document in notes.
7. mmu_tb.cpp - no cpu: fake sram with a page table, drive vas,
   verify hit/miss/walk/fault/bypass. verilator --top-module mmu.
8. paging test on cpu - C program builds a page table in sram,
   enables mmu, proves identity map + one remapped page + uart mmio
   still works through VAs. runs via cpu_sim.
9. data abort into arm7_cpu.v - fault traps like svc (new pc vector,
   the seed of the OS page-fault handler). only batch touching the core.
10. notes + regression - verilog-notes.md/project_notes.md updates,
